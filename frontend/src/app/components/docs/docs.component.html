Introduction

Quick Start

Gamify is a backend-agnostic gamification engine. Add points, badges, streaks, and leaderboards to any app in minutes — just send events via REST or our Flutter SDK.

Events
Track user actions from any source using your API key.
Rules
Define when and how users earn rewards automatically.
Rewards
Points, badges, levels — returned instantly in the response.

Installation

No SDK required for REST usage. For Flutter, add the package:

pubspec.yaml 
dependencies:
  gamify_sdk: ^1.0.0
Terminal 
$ flutter pub get

Your First Event

Get your API key from the Dashboard → Apps, then fire your first event:

cURL 
curl -X POST https://api.gamify.io/api/events/track \
  -H 'X-API-Key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"userId":"user_123","eventName":"completeLevel","data":{"level":1}}'
The response includes any rewards earned — badges, points — so you can show them in-app immediately.
Security

Authentication

API Keys

Every app you create gets a unique API key. Use it to track events from your backend or mobile SDK. Never expose your API key client-side in a web browser.

HeaderValueRequired
X-API-KeyYour app API keyRequired
Content-Typeapplication/jsonRequired
Rotate your API key from Dashboard → Apps → Regenerate Key if it's ever compromised.

JWT Tokens (Dashboard API)

The dashboard and analytics endpoints require a JWT obtained via the owner login flow. Pass it as a Bearer token:

HTTP Header 
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
Core API

Events

Events are the entry point for all gamification logic. Every user action you want to reward must be tracked as an event.

Track an Event

POST /api/events/track 🔑 X-API-Key
FieldTypeRequiredDescription
userIdstring Required Unique identifier for the user in your system
eventNamestring Required Name of the event (e.g. completeLevel)
displayNamestring Optional Human-readable name shown in the dashboard
dataobject Optional Arbitrary key-value metadata about the event
Request body 
{
  "userId": "user_123",
  "eventName": "completeLevel",
  "displayName": "Alice",
  "data": {
    "level": 5,
    "score": 9800,
    "status": "perfect"
  }
}

Register Events

Before you can use events in rules, register them via the scanner or API. This populates the event picker in the dashboard.

POST /api/events/register 🔑 X-Api-Key
Request body 
{ "events": ["completeLevel", "purchaseItem", "login"] }

Event Response

Every tracked event returns the rewards earned synchronously:

Response 200 
{
  "rewards": [
    {
      "type": "POINTS",
      "data": 100,
      "message": "+100 points for completing level 5"
    },
    {
      "type": "BADGE",
      "data": { "id": 3, "name": "Level Master" },
      "message": "Badge unlocked: Level Master"
    }
  ]
}
Logic Engine

Rules & Rewards

Rules define exactly when and how your users are rewarded. Create them in the dashboard — no redeploy needed.

Simple Rules

Simple rules trigger on a single event. Configure via Dashboard → Rules → New Rule.

Trigger Event
e.g. completeLevel
Condition
data.level >= 5
Reward
+100 points or badge

Advanced Rules

Advanced rules support compound logic — multiple trigger events, cooldowns, max awards per user, and priority ordering.

FeatureDescription
Trigger EventsOne or more event names that activate this rule
ConditionsFilter by event data fields (e.g. score > 5000)
Max Awards/UserLimit how many times one user can earn this reward
CooldownMinimum time between awards for the same user
PriorityHigher priority rules are evaluated first
ActionsAward points, grant badge, or both

Reward Response

Both simple and advanced rules return rewards in the same format inside rewards[].

If a rule's conditions are not met, or the user has already earned the max awards, it is silently skipped. An empty rewards[] array is returned.
Rewards

Badges

Create a Badge

Badges are created in Dashboard → Badges → New Badge or via API:

POST /api/badges?appId={appId} 🔐 JWT
Request body 
{
  "name": "Level Master",
  "description": "Awarded for reaching level 10",
  "imageUrl": "https://cdn.example.com/badges/level-master.png",
  "hidden": false,
  "maxAwardsPerUser": 1
}

Award Logic

Badges are awarded automatically when a rule's conditions are met. Set maxAwardsPerUser: 1 to create one-time achievement badges. Hidden badges don't appear in the user's badge list until earned.

Mobile

Flutter SDK

The official Flutter SDK wraps the REST API with a clean, type-safe interface and built-in reward widgets.

Setup

Initialize once at app startup, typically in main.dart:

Dart 
import 'package:gamify_sdk/gamify_sdk.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await GamifySDK.init(apiKey: 'YOUR_API_KEY');
  runApp(const MyApp());
}

Track Events

Dart 
final rewards = await GamifySDK.track(
  userId: currentUser.id,
  displayName: currentUser.name,
  eventName: 'completeLevel',
  data: {'level': 5, 'score': 9800},
);

if (rewards.isNotEmpty) {
  showRewardDialog(context, rewards);
}

Integrations

Webhooks

Get notified in real-time when users earn rewards. Point any HTTPS endpoint at Gamify events.

Configuration

Add webhook URLs in Dashboard → Apps → Webhooks. Gamify will POST a JSON payload to your endpoint whenever a reward event fires.

Event Types

EventFires when…
reward.pointsA user earns points
reward.badgeA badge is awarded
rule.triggeredAny rule fires (simple or advanced)
user.levelupA user reaches a new level threshold

Retry Logic

If your endpoint returns a non-2xx response, Gamify retries up to 3 times with exponential backoff: 1 min → 5 min → 30 min. Failed webhooks appear in Dashboard → Overview → Flagged Issues.

Always respond with 200 OK immediately and process the payload asynchronously to avoid timeouts.
